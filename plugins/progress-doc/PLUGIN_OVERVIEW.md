Keep an eye on a long-running agent without reading its whole transcript: a
side-panel tab shows the thread's progress doc and keeps it current as the
agent edits it.

## What you get

- A **Progress doc** entry in the thread panel's new-tab Actions list.
- **Three ways to pick the doc:** ask the agent to start keeping one, pick an
  existing file from `~/agent-progress`, or paste the path of any markdown file.
- The doc **rendered like a chat message**, refreshed every few seconds.
- A **customisable prompt** in settings, suggesting sections for active PRs,
  what's hard, progress, spec links, open questions, notable decisions and an
  archive — and asking the agent to keep working rather than block on you.

## Requirements

The thread needs a workspace: the doc is read on the machine that holds it.
